# TrexMoney (Backend Project)

This repository contains the backend for the TrexMoney financial management system.

Project description
- Designed and developed a full-stack financial management system to track income, expenses, and generate reports.
- Implemented user management, income/expense tracking, and monthly/yearly/custom reports.
- Built an admin dashboard for account control, system monitoring, and security management.
- Added expense limiter feature to set budget limits with alerts on overspending.
- Database Design: Normalized schema with users, transactions, and expense limiters tables, ensuring relational integrity with foreign keys.
